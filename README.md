# 💌 Customized Animated Wedding Invitation & Interactive Envelope

A luxury digital wedding invitation experience inspired by fine Mediterranean stationery. Built with pure HTML, vanilla CSS, and JavaScript.

## ✨ Features

- **Realistic 3D Envelope Opening**: Choreographed wax seal unlock with realistic flap-unfolding and downwards envelope glide.
- **Dynamic Monogram & Seal**: Wax seal dynamically reflects couple initials (e.g. S&J).
- **Interactive Scratch-to-Reveal**: Real-time scratch foil with confetti celebration and golden shimmer dissolve.
- **Live Countdown Timer**: Styled with Victorian cartouche and delicate botanical flourishes.
- **Auto-Scrolling 4:5 Photo Carousel**: Borderless gallery flanked by hand-drawn leaf vine illustrations.
- **Interactive Schedule & Maps**: Timeline with custom badges, calendar add buttons, and Google/Apple Maps integration.
- **Live RSVP System**: Built-in guest response flow with real-time confirmation tracking.
- **Admin Customization Panel (`admin.html`)**: Complete control over names, dates, text, theme colors, carousel speed, and photo uploads directly from your device.
- **RSVP Dashboard (`dashboard.html`)**: Real-time guest attendance and dietary overview.

## 🚀 How to Run

Simply open `index.html` in any modern web browser or host on GitHub Pages, Netlify, or Vercel.
- **Guest Invitation**: `index.html`
- **Admin Panel**: `admin.html`
- **RSVP Dashboard**: `dashboard.html`
